# The Appliance Clinic Corporate Operations Manual & Compliance Framework

*Published by Ross Tax Pro Software Co. Governance Division*

---

## 1. Accounting Policies & Dual-Signoff Internal Controls

All commercial business event mutations inside the architecture—including inventory purchases, fleet line allocations, and direct customer payments—must be processed via double-entry systems matching Debits and Credits exactly.

- **Approval Gateways:** Ledger modifications altering balances exceeding $10,000 require automated dual-token authorization from the Chief Financial Officer (CFO) and an active System Administrator.
- **Square Integrations:** Daily Point of Sale closures must run automatic reconciliation reports matching Square API event telemetry records directly to general ledger records.

---

## 2. Information Security Protocols (SOC2 & HIPAA Alignment)

To maintain security across infrastructure pipelines, all application endpoints operate under strict audit requirements.

- **Least Privilege RBAC Controls:** Active users can only view standard records if their signed JWT explicitly includes roles with authorization definitions for that module.
- **Audit Trailing Logs:** High-risk entity data modifications trigger immutable write logs containing user ID hashes, network IP vectors, and accurate timestamp values.
- **MFA Enforcement:** All users with roles of `OWNER`, `ADMINISTRATOR`, `ACCOUNTING`, or `PAYROLL` must have Multi-Factor Authentication enabled. TOTP-based MFA is managed via `otplib` and stored as an encrypted secret per user record.
- **Password Policy:** All passwords must be hashed using `bcryptjs` with a minimum cost factor of 12. Plaintext passwords are never stored or logged.
- **Token Lifecycle:** JWT tokens expire after 8 hours. Refresh tokens are not persisted server-side; users re-authenticate after expiry.

## 3. Field Service Operations & Safe Fleet Guidelines

- **Field Safety Compliance:** Technicians must submit digital vehicle inspection checklists before starting service dispatch operations.
- **GPS Telemetry Capture:** Route optimizations run dynamic tracking updates to keep operational dispatch modules updated. Technicians are required to wear company-issued protective equipment during service calls.
- **Work Order Lifecycle:** All work orders must follow the state machine: `UNASSIGNED → SCHEDULED → EN_ROUTE → IN_PROGRESS → COMPLETED` or `CANCELED`. Status transitions are logged via the audit system.

---

## 4. HR & Payroll Compliance

- **Time Card Accuracy:** Technicians and field staff must clock in and out via the platform. Supervisors must review and approve time cards before payroll processing.
- **Payroll Processing:** Payroll entries are generated by the `PAYROLL` role only. Each entry records `grossPay`, `netPay`, and `taxWithheld`. Direct deposit execution is tracked via the `isDirectDepositExecuted` flag.
- **IRS Form 941 Reporting:** The `TaxService.generateForm941Data()` method aggregates quarterly payroll data for federal filing. Combined Social Security rate: 12.4%. Combined Medicare rate: 2.9%.

## 6. Data Retention & Compliance

- Audit logs are immutable and must be retained for a minimum of 7 years per SOC2 requirements.
- Customer PII (email, phone) must be encrypted at rest. Ensure PostgreSQL encryption at the storage layer.
- All API endpoints are rate-limited to 100 requests per 60 seconds per IP address.
